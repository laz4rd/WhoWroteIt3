# Tech Apex assets

Place the supplied artwork in `public/` using these names:

| File | Purpose |
| --- | --- |
| `public/tech-apex-background.webp` | Main illustrated Tech Apex background. PNG is also fine if the CSS filename is updated. It is automatically overlaid and darkened for readable gameplay. |
| `public/tech-apex-logo.svg` | Optional logo/wordmark for the next visual pass. |
| `public/fonts/tech-apex-display.woff2` | Optional display font. Add an `@font-face` in `app/globals.css` when its licence permits web use. |

No icons are required for this build: rank and locker states use text-and-shape treatments until custom badges are available.
